Solo, Undo, a mixer and a Limit slider

The device as it would look in Live. Everything else stays where it is. The four changes are marked 1–4. The mockup is live: click Mix in the waveform header, drag the faders and the Limit slider, and click M, S, Solo or Undo.

Shown at 1.4× Live's size. Scroll sideways on a small screen.

1Solo

  • The row under the waveform gets Solo next to Mute. To make room, Random file becomes Random (one cell instead of two).
  • Several files can be soloed at once. While any file is soloed, the others are silent but keep running in time, the same as Mute.
  • In the file grid, a soloed file gets a blue bar and the silent ones dim.
  • Solo is saved with the set. It isn't stored in memory slots, so recalling a slot never changes it.

2Undo

  • Undo sits right of Random all and Depth, in the empty cell under Shape.
  • It steps back through the last 8 jumps: Random all, Random file, Random <tab>, Init, and recalling a memory slot. Each press goes one step further back.
  • It brings back the settings and the locked loops exactly as they were. Files and slicing are not touched.
  • Greyed out when there is nothing to undo. The undo history is not saved with the set.

3Mixer

  • The waveform header gets a Wave / Mix switch. Mix shows all 16 files side by side in the same space.
  • Each fader is that file's Volume (−36 to +6 dB), the same value as Volume on the Env tab. Double-click a fader for 0 dB.
  • M and S under each fader are the file's Mute and Solo. The thin light line inside each fader shows what that file is playing.
  • Click a number to select that file. The header shows its name and level.

4Limit slider

  • 0: off. 10 (the default): today's safety catch, nothing pushed.
  • 10 → 100: the mix is pushed up to +18 dB into the limiter, and it lets go faster (80 → 15 ms). Louder and denser.
  • 75 → 100: soft clipping is blended in for grit. Back the slider off until the clipping is gone.
  • The output never goes above −0.3 dB. It looks 2 ms ahead, so the limiter itself doesn't crackle. The bar under Comp shows comp and limiter together.

The graph shows where loud peaks end up for the slider value. It's a guide, not a measurement: real material with fast hits gets a little less than the curve.
