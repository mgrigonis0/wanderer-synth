# Wanderer

A Max for Live instrument for Live 11 (Max 8): up to 16 audio files, sliced and played by a stochastic clock per file, with Free/Lock loops, memory slots and an output chain.

- `devices/wanderer/HANDOFF.md`: current state and next step. Start here.
- `CONVENTIONS.md`, `HANDOFF_GUIDELINES.md`: shared rules and how handoffs are kept.
- `legacy/`: the previous build (brain and voice 2026-10-12e, main patch and panel 2026-10-08f) and its simulation tools. Reference only; a rebuild is in progress.
