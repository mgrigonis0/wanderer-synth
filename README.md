# Wanderer

A Max for Live instrument for Live 11 (Max 8, Mac): up to 16 audio files, sliced and played by a stochastic clock per file, with Free/Lock loops, memory slots and an output chain.

- **Install:** download `wanderer-mac.zip` from the release "Wanderer — latest build" and follow `devices/wanderer/INSTALL.md`.
- `devices/wanderer/HANDOFF.md`: current state and next step. Start here.
- `CONVENTIONS.md`, `HANDOFF_GUIDELINES.md`: shared rules and how handoffs are kept.
- `legacy/`: the previous gen~ build (reference only).
